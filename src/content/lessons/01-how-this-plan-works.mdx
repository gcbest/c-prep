## Why this matters

You have two to three days, so the order matters more than the volume. This plan puts the highest-yield material first: SQL and Java reading skills, then backend, Angular, testing and coding, and finally security, design and leadership. Candidate-reported Citi screens have included SQL, a Spring/Java segment and an Angular segment, so the plan is weighted that way.

## Core idea

Every lesson has the same shape, so you always know what comes next:

1. **Why this matters**, then **Core idea** and one short **Example**.
2. **Practice**: questions are hidden until you click *Reveal*. Grade yourself *Missed*, *Partial* or *Strong*. Misses feed the Progress page.
3. **Say it out loud**: one untimed 60-90 second answer. Speaking is the skill you are really rehearsing.
4. **Go deeper**: collapsed, optional.

Three rules keep this calm:

- **Skipping is fine.** *Skip for now* never blocks the path; skipped lessons wait on the Progress page.
- **Short on time?** Turn on *Compress mode* in Settings to fit the plan into two days. It hides the optional lessons and a few extras, and keeps the order.
- **Nothing here is timed.** There is no mock interview. Leftover time goes to redoing misses.

### Choose your backend

The role names Java, so Java / Spring Boot is the default. Choose Python / FastAPI only if you expect to be interviewed in it. This swaps the bodies of lessons 6-9 and 17 and nothing else.

## Example

A good day looks like this: read a lesson (15-35 minutes), answer its questions before revealing, say the answer out loud once, tick *Mark complete*, take a break. If you tire, stop at a lesson boundary.

```text
Day 1  SQL (3 lessons) -> Java -> Backend (4) -> Angular (2)   ~4.5 h
Day 2  Angular, RxJS -> Testing (3) -> Coding (3)               ~4.5 h
Day 3  Security -> Architecture -> Design -> Leadership -> Review ~3.75 h
```
